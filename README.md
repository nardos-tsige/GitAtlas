# GitAtlas

A GitHub profile and repository explorer. Search any username, browse their repos, filter by language, sort by stars or forks, and read READMEs rendered as markdown. Recent searches are saved locally.

## Stack

- React 19 + TypeScript
- Vite
- React Router
- Tailwind CSS v4
- react-markdown + remark-gfm

## Run

```bash
npm install
npm run dev
